# Optional diagram refinement with Codex

Support Packages, Layers, the three C4 views, and the seven static UML diagrams. Refine Activity and Sequence from code analysis. Offer Original and Refined views, with concise responsibility labels, important relationships, and evidence in the inspector. Packages, Layers, and C4 Components support navigating successively deeper groups with breadcrumbs.

Build an inventory of in-scope symbols, entry points, manifests, relationships and unresolved associations before visual limits. Select relevant code and documentation excerpts. Exclude credential files, redact recognized sensitive values, and show coverage, omissions and the exact context sent to Codex. Let the user remove excerpts or focus on a region.

Use the installed Codex CLI and its authentication. Discover it on PATH or accept its configured path. Verify the CLI supports the isolated invocation. Run in a temporary directory with an ephemeral read-only session, controlled settings, and execution tools, connectors and search disabled. Send only the explicitly approved context via stdin. Receive typed JSON through an output schema. Keep generation in the background, with one active job per project, cancellation and a timeout.

Allow labels, summaries, explanations, highlights, and evidence-backed groups. Layers may reclassify modules. C4 HTTP associations may select an existing candidate generated by the analyzer. Validate references, scope, group topology, evidence and precedence of manual declarations. Present unresolved claims under Needs confirmation. Validate the user-selected changes again before saving. Generate exports locally. Reuse the static UML renderers and preserve their operation order, signatures, and relationship semantics.

Expose authenticated preview, job, save and history endpoints. Bind jobs to the approved context hash and original project. Reject saving against changed evidence or declarations. Persist approved selections and a renderable version under the project's ignored `.nodex/diagram-refinements/`, with atomic writes, a file lock and revision checks. Load compatible active versions offline. Offer a historical view when the underlying code differs.

Cover all diagram targets with tests. Check recursive navigation across folders, ambiguous HTTP routes, unsupported database claims, invalid references, cyclic groups, rendering injection, consent, cancellation, project switching, concurrent saves, stale evidence, and offline history. Verify a real desktop generation with an authorized test project, the full Rust and web suites, TypeScript, and a production build.
